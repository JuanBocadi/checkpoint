# Imagenes y creditos de Checkpoint

Portadas, ilustraciones y capturas obtenidas de las fichas oficiales de los videojuegos en Steam el 23/11/2026. Los archivos se sirven localmente para que la interfaz no dependa de solicitudes a terceros.

El material pertenece a sus respectivos titulares. Se utiliza para identificar y presentar los juegos en este proyecto academico; los creditos no implican una licencia abierta ni una afiliacion oficial. La interfaz y los iconos SVG se desarrollaron para Checkpoint.

Las seis fichas iniciales se relacionan con estas imagenes por su titulo. Un juego nuevo sin material asociado utiliza una portada grafica de respaldo. No se modifican los datos ni los permisos del catalogo.
